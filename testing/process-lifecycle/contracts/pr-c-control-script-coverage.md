# PR C controlled-human control-script coverage contract

This feature-owned gate measures thirteen changed production JavaScript control sources with Node 22's built-in test coverage: the prior ten helpers, `acceptanceExecutionProfile.mjs`, `exhaustiveAcceptanceEvidence.mjs`, and the coverage runner itself. It is additive to the existing controlled-human source command: the original Node test segment, including the optional local PostgreSQL integration test, remains intact. The measured child executes the non-optional helper suites, direct-import suites for both newly governed controls, the runner self-test under its import guard, and genuine existing consumer scenarios. The real credential-preflight entrypoint fixture remains mandatory.

## Acceptance boundary

- The inventory contains exactly the thirteen source paths declared by `scripts/runPrCControlledHumanScriptCoverage.mjs`, each bound to its current SHA-256 digest. A hardcoded self-test independently pins the exact source, test, producer/file, and scenario-name inventories so removing an entry from the runner's own constants cannot self-validate.
- Node's built-in LCOV reporter must emit authentic non-empty coverage. Every inventory path remains visible; an unloaded historical helper is disclosed truthfully as `loaded: false` with zero measurement and is never silently excluded or force-imported. Because this correction deliberately executes direct imports of `acceptanceExecutionProfile.mjs` and `exhaustiveAcceptanceEvidence.mjs` plus the runner self-test, those three paths must each be loaded with a positive non-empty line measurement; silent omission of any of those intended measured paths fails closed. This scoped rule does not globally reject a truthful historical `loaded: false` row.
- The test process must pass with zero failed, cancelled, skipped, or todo tests. A green process without TAP, LCOV, or all eight exact scenario reports fails closed.
- Scenario evidence is written by the exact owning test file only after its named assertions pass. Exact producer/file/name inventories reject missing, duplicate, skipped, substituted, or stale scenario output; suite exit and the runner's expected scenario array never synthesize a passed scenario.
- Existing consumers exercise the profile through the installed-Playwright temporary synthetic metadata configuration and the exported local browser runner with synthetic transports. Existing `runExhaustiveAcceptanceReport.test.mjs` cases spawn the real `runExhaustiveAcceptanceReport.mjs` wrapper for malformed declaration, planned-scope, local/hosted-substitution, and hostile-provenance paths. These descriptions do not claim that every repository Playwright config or a real browser batch executed.
- The actual production credential-preflight entrypoint runs in a clean isolated Git checkout with the accepted base as ancestor, exact source-before/source-after identity, Node 22, the fixed command, and one exclusive output file. External test-only modules replace only `pg.Client`, Supabase client construction, and `fetch`; no production injection surface is added and no network or real database is reachable.
- The isolated checkout overlays only the governed candidate inventory plus the five exact removed `pr264-controlled-human-{checkpoint,edge-deploy,prepare,quiesce,verify}.yml` workflows, and verifies byte-or-absence equivalence before its synthetic commit. `.agent/`, `output/`, `tools/`, `docs/marketing/`, `.env*`, and `scripts/testPilotOperationsRecoveryPostgres.mjs` remain expressly outside the overlay.
- Mandatory negatives cover wrong output path, dirty source, nonancestor source, source change during execution, output collision, signing-key whitespace and bounds, password type and maximum length, and the 16 KiB artifact limit.
- The report binds the accepted base, current HEAD, governed working-tree digest, exact source hashes, exact test inventory, exact scenario-report hashes, built-in line/branch/function measurements, and uncovered line/branch/function paths.

No new numeric percentage threshold or performance budget is defined. The gate requires authentic execution and complete measurement; percentages and uncovered paths are disclosed for review.

The built-in LCOV measurement covers execution in the measured Node test workers. Subprocesses spawned by genuine report-wrapper scenarios and the isolated production-entry child are separately mandatory scenario contracts and are not folded into the parent LCOV counts. Their candidate source hashes or result identities remain independently checked by their existing production contracts; the report must not imply that child-only branches contributed to the percentages. The outer canonical invocation of `runPrCControlledHumanScriptCoverage.mjs` is the actual entrypoint and is likewise separate from child numeric coverage; only the self-test import contributes that runner's child LCOV measurement.

## Evidence and exclusions

The canonical command creates one fresh exclusive attempt beneath the resolved configured `output/pr-c-controlled-human-script-coverage/` boundary, writes only its sanitized JSON summary there, and emits the complete sanitized measurement plus report digest to the canonical command log. It preserves prior attempts. Raw TAP, raw LCOV, temporary scenario reports, temporary Git checkouts, transport traces, database values, URLs, credentials, and V8 dumps are deleted or remain outside retained evidence. The fixture environment is allowlisted and does not inherit hosted, provider, GitHub, Netlify, Supabase, controlled-human secret, `NODE_OPTIONS`, `NODE_V8_COVERAGE`, or arbitrary Git configuration. Its empty owned Git config disables system configuration and binds `safe.directory` only to the resolved governed root; wildcard trust, hooks, credential helpers, and extra inherited Git config are excluded.

This is local synthetic/source evidence. PostgreSQL, hosted credential delivery, deployment, service-credential authentication, temporary-token authentication, human testing, real providers, pilot, production, readiness, and certification remain separate `not_run`, planned, or prohibited boundaries.

The prior ten-source state is known incomplete and must not be restored or represented as canonical acceptance. Never delete retained measurements, add production injection parameters, weaken TLS or source identity, allow skips, exclude a governed source, relax Environment approval, or restore secret relay.
