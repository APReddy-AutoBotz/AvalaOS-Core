# Synthetic invoice review SOP

This is fictional testing material. It contains no production or customer data.

1. Capture an invoice from the shared inbox.
2. Validate its reference against the purchase order in Synthetic ERP.
3. Investigate a mismatch and record a reason.
4. Obtain human approval before any payment-related action.
5. Record an audit note and communicate the decision.

Owner: synthetic finance team.
Completion: the exception has a documented human decision.
Manual effort: 15 minutes per invoice. This deliberately conflicts with the meeting transcript's 12 minutes and must not silently win.
Monthly volume, machine identity, rollback and API write coverage: unknown.

Do not interpret this SOP as evidence that any application is approved for autonomous operation.
